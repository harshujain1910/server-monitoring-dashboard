# 🚀 Server Monitoring Dashboard
Real-time server monitoring dashboard with live CPU &amp; memory visualization, alerts, and authentication using Flask

## 🔥 Features
- Live CPU and Memory monitoring
- Real-time graphs using Chart.js
- Alert system for high usage
- Login authentication

## 🛠️ Tech Stack
- Python
- Flask
- psutil
- JavaScript (Chart.js)

## ▶️ How to Run
```bash
pip install flask psutil
python app.py
